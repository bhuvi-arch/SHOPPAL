# 🛍️ Shoppal – AI Price Comparison Platform

An AI-powered price comparison tool that helps users find the best deals across Amazon, Flipkart, and Nykaa using AI-driven "Buy Now or Wait" advice.

## ✨ Features
- 🔍 **Smart Search**: Search products with AI price analysis.
- 🤖 **AI Price Prediction**: Decision Tree logic tells you if you should "Buy Now" or "Wait".
- ❤️ **Favorites**: Save products to your wishlist.
- 👤 **User Profiles**: Manage addresses, orders, and skin profile (for skincare recommendations).
- 🔐 **JWT Authentication**: Secure login/register with hashed passwords.

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python, Flask
- **Database**: MongoDB
- **Auth**: JWT, bcrypt

## 📊 Test Results
- ✅ **Functional Accuracy**: 35/35 test cases passed (100%)
- ⚡ **Search Response Time**: 343ms
- ⭐ **User Satisfaction**: 4.5/5

## 🚀 How to Run (Local Setup)
1. Install Python and MongoDB.
2. Clone this repo.
3. Run `pip install -r requirements.txt` in the backend folder.
4. Run `python backend/app.py`.
5. Open `index.html` in a browser.
